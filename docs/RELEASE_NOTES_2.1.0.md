# LocusMimic 2.1.0 更新内容

标签：`20100-2.1.0`

LocusMimic 2.1.0 面向 Android 11（API 30）及以上的 `arm64-v8a` 设备。

## 新增

- 新增 **NFC 模拟**。
- 新增 **蓝牙模拟**。
- 路径模拟摇杆模式新增 **“指哪儿到哪儿”**。
- 路径模拟支持选择指定路点作为起始路点。
- 路点菜单新增删除操作。

## 优化

- 优化路径模拟配置，启动期间可实时调整速度及大部分运行参数。
- 优化摇杆模式的起点选择、移动轨迹和地图图标显示。

## 修复

- 修复关闭 GNSS 状态后无法正常搜索地址的问题。
- 修复摇杆模拟偶发不显示移动轨迹的问题。
- 修复路径模拟停止后仍保留已走路径的问题。
- 修复平滑停止清除路径时，最终位置可能跳回路线起点的问题。
