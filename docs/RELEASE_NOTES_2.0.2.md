# LocusMimic 2.0.2

标签：`20002-2.0.2`

这是 LocusMimic V2 的维护版本，面向 Android 11（API 30）及以上的 `arm64-v8a` 设备。

## 本次更新

1. 修复进入赞助页就崩溃的问题
2. 优化在 Android 11 设备上的 UI 显示效果
3. 新增运行日志导出（权限刷新失败的可详细导出日志发给群管理）
4. 新增在最新的更新检查

## 升级说明

- 旧版用户升级后，可在应用内按权益迁移或恢复流程找回已拥有的权益。
- Root 与 LSPosed 仅在对应运行模式下需要；请根据设备环境与测试范围选择最小必要权限和作用域。
- 本项目仅用于合法、已授权的测试、开发调试和学习研究。
