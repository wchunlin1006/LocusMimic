# LocusMimic 2.3.0正式版 | RC版 更新日志

## 新增

- 新增 **基站模拟**
  - 支持基站环境扫描，可读取系统返回的蜂窝环境，支持保存为模板；
  - 支持通过地图匹配基站，支持将匹配结果保存为模板；
  - 支持导入本地基站数据库；
  - 支持基站模板管理；
  - 支持模拟位置根据导入的基站数据库动态匹配蜂窝基站，
- 新增 **跟随** 控制方式，可根据实时采集的真实路径推进，并沿用路径规划中的速度、步频与平滑设置。
  - 支持选择起点，默认使用真实位置，地图选点完成后显示“从这里开始跟随”气泡。
  - 支持“自动停留”开关及“停留判定时间”，可设置真实位置连续停留多久后记录停留路点。
- 新增真实 **路径采集**，支持采集、暂停、继续及保存路径，从真实位置开始记录。
- 新增路径规划 **自然速度变化**设置，支持在设定速度附近平缓变化，默认关闭。
- 新增生成跑道 **不规则度** 和重新生成功能；各圈独立变化，预览与实际运行采用同一版本的形状算法。
- 新增 **自动启停**，支持按指定应用或 Activity 配置触发规则及每日时间范围；可用性受运行模式、授权和必要权限限制。
- 新增地图 **方向跟随**，即地图支持跟随设备旋转而旋转，让行进方向始终朝向设备正上方

## 优化

- 优化 **自然速度变化** 算法，让速度变化/平均步频曲线更真实
- 优化 **平滑启停** 算法，可根据不同速度匹配自然加速度，然加速与减速更加平缓和自然
- 优化移动图钉的连续插值与轨迹末端同步
- 优化部分界面的功能结构和UI设计
- 优化全局液态玻璃算法，在保留既有玻璃视觉的同时，较少大量重复AGSL处理，提升管理器流畅性
- 优化路径几何缓存、数据准备、重复状态更新，减少主线程工作和无效重组（解决启动模拟后部分应用卡顿或异常退出的问题）
- 优化模板绑定逻辑

## 修复

- 修复百度地图下图钉、普通路点抖动的问题。
- 修复使用高德定位通道的应用存在定位漂移的问题
- 修复使用高德地图时概率性出现地图瓦片突然丢失的问题


## 升级提醒

- 更新模块后需要重启手机，使系统进程加载新代码；切换运行模式时遵循应用中的重启提示。
- 模板更新不自动替换已有绑定；需要使用新版本时，请重新绑定并重启设备
- 旧跑道保留其已保存的形状版本；需要使用新算法时，请重新生成并保存。
- 跟随与采集的可用性受运行模式、能力授权、定位权限和真实定位条件影响，不代表所有模式均已支持。
- 基站模拟当前仅支持 Hook 模式。环境扫描结果以系统返回为准，不保证一定包含邻区；地图匹配依赖数据库覆盖与时效，匹配出的关系和信号估算不等于现场实测。
