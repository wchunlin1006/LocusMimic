# LocusMimic 2.0.0

标签：`20000-2.0.0`

这是 LocusMimic V2 的正式发布版本，面向 Android 11（API 30）及以上的 `arm64-v8a` 设备。

## 本次更新

- 重构位置模拟、路径模拟、应用作用域、主题与设置界面。
- 新增试用与订阅权益流程，支持邮箱绑定、订阅记录、权益恢复和设备迁移。
- 整合地图展示、地点搜索、地址解析与路径规划，支持受管理地图服务和用户自有地图凭证。
- 完善应用兼容配置、定位通道、坐标系与运行模式管理。
- 优化路径编辑、自动与摇杆控制、启动授权、通知与留言、暗色主题及日常交互。

## 升级说明

- 旧版用户升级后，可在应用内按权益迁移或恢复流程找回已拥有的权益。
- Root 与 LSPosed 仅在对应运行模式下需要；请根据设备环境与测试范围选择最小必要权限和作用域。
- 本项目仅用于合法、已授权的测试、开发调试和学习研究。
