# LocusMimic 2.0.6 更新日志

标签：`20006-2.0.6`

LocusMimic 2.0.6 面向 Android 11（API 30）及以上的 `arm64-v8a` 设备。

## 新增

- 新增地图 2D/3D 视图切换。
- 新增标准、卫星地图图层切换，并支持记忆图层选择。
- 新增订阅权益多设备绑定列表及设备管理功能。
- 新增百度地图全球地点搜索能力。

## 优化

- 优化多设备绑定、解绑及权益刷新逻辑与 UI 设计。
- 优化高级材质性能，整体资源开销降低约 30%，界面流畅性明显提升。
- 完善英文界面翻译，目前主要由机器翻译完成，后续将持续校对。

## 修复

- 修复权益状态、绑定数量及设备记录未及时刷新的问题。
- 修复高德标准地图可能不显示建筑、道路及 POI 信息的问题。
