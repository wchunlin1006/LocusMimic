# LocusMimic 2.2.0-rc.12 更新日志

## 新增

- 新增“跟随”控制方式，可根据实时采集的真实路径推进，并沿用路径规划中的速度、步频与平滑设置。
  - 支持选择起点，默认使用真实位置，地图选点完成后显示“从这里开始跟随”气泡。
  - 支持“自动停留”开关及“停留判定时间”，可设置真实位置连续停留多久后记录停留路点。
- 新增真实路径采集，支持采集、暂停、继续及保存路径，从真实位置开始记录。
- 路径规划新增“自然速度变化”选项，在设定速度附近平缓变化，默认关闭。
- 生成跑道新增可调“不规则度”和重新生成功能；各圈独立变化，预览与实际运行采用同一版本的形状算法。

## 优化

- 路径规划与确认跑道 抽屉改为自由停靠，方便一边调整一边看路径规划效果
- 优化路径、跟随和采集期间的图标与镜头动画，改善分段移动的视觉感受。
- 完善移动方向朝上的地图视角；
- 优化模板绑定逻辑

## 修复

- 修复百度地图下图钉、普通路点抖动的问题。
- 修复蓝牙模式“对外广播－GATT 服务”说明抽屉中文字重叠的问题。
- 路径模拟运行期间，对调整跑道、修改路点等受限操作统一提示“路径模拟未停止，不可操作。”。

## 升级提醒

- 更新模块后需要重启手机，使系统进程加载新代码；切换运行模式时遵循应用中的重启提示。
- 模板更新不自动替换已有绑定；需要使用新版本时，请重新绑定并重启设备
- 旧跑道保留其已保存的形状版本；需要使用新算法时，请重新生成并保存。
- 跟随与采集的可用性受运行模式、能力授权、定位权限和真实定位条件影响，不代表所有模式均已支持。
