# LocusMimic 2.0.5 更新日志

标签：`20005-2.0.5`

LocusMimic 2.0.5 面向 Android 11（API 30）及以上的 `arm64-v8a` 设备。

## 新增

- 支持一个订阅绑定多个终端
- 升级液态玻璃（高级材质）视觉，完成度60%，性能还需优化。

## 优化

- 优化加速度计步能力，适配通过摇晃传感器统计步数的应用。
- 优化地图渲染逻辑，打开设置、抽屉或弹窗时不再反复重建 WebView。
- 优化路径模拟控制区、速度调节、步频设置和路径规划面板的交互与视觉表现。
- 优化运行日志，支持详细记录启动、协议、配置、模拟、Hook、定位投递及步频链路。

## 修复

- 修复升级或重新进入应用后，部分用户配置可能被基线配置覆盖的问题。
- 修复部分机型震动反馈异常或触发权限错误的问题。
- 修复 Root 模式并发初始化可能造成注入失败的问题。
- 提升 Hook 挂载、位置投递、步频模拟及异常退出问题的可诊断性。
