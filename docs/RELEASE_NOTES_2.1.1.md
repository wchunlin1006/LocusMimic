# LocusMimic 2.1.1 更新日志

此次更新分正式版与RC版，正式版主要集中功能迭代与优化，RC版则在正式版的基础之上，更激进地对底层Hook及定位通道进行重大调整，其目的是想提升模拟的可靠性与稳定性，但由于测试有限，实际是否具备更好的体验，还请自行体验与测试，最后，感谢大家的支持。

## 正式版 · 2.1.1

### 新增

- 新增跑道规划，支持调整跑道位置、大小、方向、起跑点及圈数。
- 路径规划新增真循环，即循环连接终点与起点继续运行。
- 收藏位置、收藏路线支持重命名。

### 优化

- 优化起始路点使用专属图标，便于识别。
- 优化定位、通知、ROOT、模拟位置及画中画的按需权限申请，统一使用弹窗引导。
- 调整高级材质关闭时的页面与抽屉背景，改善内容辨识度。
- 完善权益恢复和授权刷新流程，改善设备安全密钥异常时的处理。
- 优化地址搜索去重并扩大检索范围。

### 修复

- 修复收藏路线重新加载后，路点停留时间丢失的问题。
- 修复免费权益在重启 App 后，地图服务会恢复成默认的问题。
- 修复切换语言后需要重启应用才能生效的问题。
- 修复路径规划期间搜索、收藏与菜单入口响应延迟的问题。

## RC 版 · 2.1.1-rc.1

### 新增

- 新增自动启停：指定应用或 Activity 进入前台时自动启动模拟，退出后自动停止；支持按应用单独配置启停规则，手动操作可接管自动模拟。
- ROOT 模式增加严格模式、宽容模式选项，提升不同场景下的可用性。

### 优化

- 对 Hook、系统、ROOT 和开发者模式进行探索性改造，完善模拟状态传递、回调调度、坐标输出及异常处理。
- 优化主动刷新的调度与请求约束处理，减少重复派发，并在没有真实 GPS 定位结果时继续按模拟数据工作。
- 优化近似位置权限适配及部分厂商定位 SDK 的挂载、请求生命周期处理。
- 改善无法获得真实 GPS 定位结果时的模拟输出，不依赖真实 GPS Fix 推进位置与路径。
- 修复路径暂停时定位时间戳重复的问题，静止位置保持更新。
- 完善请求取消、监听注销及停止模拟后的清理，减少残留回调。
- 改善主动刷新调度，减少重复派发，更准确地遵守请求间隔、最小距离和次数限制。

## 安装包

- 正式版：`LocusMimic-2.1.1-20261012.apk`
- RC 版：`LocusMimic-2.1.1-rc.1-20261012.apk`
- 安装代码：`20201`
- Android：11 及以上
- 架构：`arm64-v8a`

正式版与 RC 版使用相同签名。切换版本前请先停止模拟；若 Android 不允许直接覆盖安装，请先备份配置。卸载应用会清除应用数据。
