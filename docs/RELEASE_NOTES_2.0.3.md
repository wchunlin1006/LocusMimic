# LocusMimic 2.0.3

标签：`20003-2.0.3`

这是 LocusMimic V2 的特性与维护版本，面向 Android 11（API 30）及以上的 `arm64-v8a` 设备。

## 本次更新

### 1. 新增
- **新增注入模式**：
  - **极速挂载**：进程就绪即立刻挂载，时序最短、开销最低，且可避免首帧泄露，适用于绝大多数主流 App 及无特殊类加载机制的目标应用。
  - **双阶重试**：进程就绪时执行首次挂载，应用 onCreate 完成后对延迟加载的定位类库追加一次补充挂载，适合使用厂商扩展定位 SDK 或自定义类加载器的应用（如部分地图、出行类 App）。
  - **经典兼容**：跳过进程就绪阶段的挂载，完全等到应用 onCreate 完成后才加载，是 V1 版的注入方案；适合对启动过程敏感的应用，但存在首帧泄露（即启动时是真实位置，然后切换到模拟位置，若应用缓存首帧，则可能会模拟无效或被检测）。
- **新增在线更新**
- **新增邮箱换绑功能**
- **路点停留新增支持手动输入时间**

### 2. 优化与修复
- 修复相机位置设置为“模拟位置”时，但实际会聚焦到天安门的问题
- 优化设置持久化逻辑，解决重启管理器设置会自动重置为默认设置的问题
- 优化通知与留言界面在暗色主题下的可视效果
