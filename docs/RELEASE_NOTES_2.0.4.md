# LocusMimic 2.0.4 - 定位兼容与稳定性史无前例的增强

标签：`2.0.4`

LocusMimic 2.0.4 重点改善第三方应用中的坐标、地址与 GNSS 状态一致性即稳定性，同时完善各厂商定位通道的自适配能力。本版本面向 Android 11（API 30）及以上的 `arm64-v8a` 设备。

## 本次更新

### 1. 定位兼容与地址一致性

- 深度凸优化统一各商定位通道中的转换与输出规则。
	- 解决BD地图跳海的问题。
	- 解决部分app闪退问题
	- 解决闪动X园步数使用为 0 的问题（加速度步频适配器）
	- 实现更精准的坐标系自动匹配与转换，解决更多app定位便宜问题
	- 路径模拟期间，实现按移动距离自动更新地址信息。
	- 解决启动模拟后，在部分app中坐标地点和地址信息不一致的问题。
	- 优化 GNSS 状态与定位回调的同步，提升依赖 GPS 状态应用的兼容性。

### 2. 路径模拟与驾驶舱

- 步行和跑步速度增加配速显示，骑行和驾车使用 `km/h`；自定义速度同步展示 `m/s`、配速和 `km/h`。

### 3. 设置

- 新增设置备份与还原，可加密备份收藏夹、客户端设置及自有地图凭证。
- 新增加速度步频适配能力，为有需要的运动类应用补充更自然的步频数据。
